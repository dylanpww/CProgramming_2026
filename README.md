🛠️ How to Compile & Run

Method 1: Visual Studio 2022 (Recommended)

Open the desired solution file (e.g., Ch5.slnx or ProgMethods.sln) in Visual Studio 2022.

Set the target project as Startup Project in Solution Explorer.

Build and run using Ctrl + F5 (Run Without Debugging) or F5 (Start Debugging).
